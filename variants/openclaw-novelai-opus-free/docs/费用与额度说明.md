# Opus 免费增强模式费用与额度说明

## 目标

这个变体的目标是：在活跃 Opus 订阅下，使用当前实测为免费的图片创作和编辑能力，同时**不消耗 NovelAI Image Anlas**。

它不是“所有服务都免费”的承诺，也不是“无限生图”模式。它只允许当前工具明确估算为 `0 Anlas` 的图片请求。

## 允许的功能

| 功能 | 是否允许 |
| --- | --- |
| 小说大纲、续写、改写、审阅、总结 | 允许，不调用图片点数 |
| 本地读取和整理小说资料 | 允许 |
| 账户和订阅查询 | 允许，只读 |
| Anlas 费用估算 | 允许，只估算不执行 |
| 标签建议 | 允许，不生成图片 |
| Prompt、负面 Prompt、Seed 和场景规划 | 允许，只是准备工作 |
| 单张图片生成、图生图、局部重绘 | 只有 Opus 且估算明确为 `0 Anlas` 才允许 |
| 已经编码的 Vibe 生图 | 允许；不能在本模式中编码新的 Vibe |
| 标注 | 允许作为预处理 |
| Director 线稿、草图、去杂物、上色、表情 | 正常尺寸下允许；去背景禁止 |

## 生图必须同时满足的条件

1. 当前账户是有效 Opus 订阅；
2. 当前 MCP 暴露 `estimate_anlas_cost`；
3. 先把最终参数交给估算工具；
4. 返回明确的数值 `0 Anlas`；
5. 只生成一张；
6. 正常分辨率，保持在 `1024x1024` 等效像素面积以内；
7. 不超过 28 steps；
8. 图生图/局部重绘可以使用底图和遮罩，但必须通过精确费用估算；Vibe 只能使用已有编码；Director 只能使用线稿、草图、去杂物、上色、表情；
9. 不批量、不并行、不自动重试。

任一条件不满足，都不调用生图工具。每次图片操作后都要重新查询余额；如果 Anlas 减少，立即停止本模式的后续图片操作。

## 明确禁止的功能

- 新的 Vibe 编码；
- Precise Reference；
- Director 去背景；
- Enhance；
- 专用放大；
- 多张图片、多样本和并发生成；
- 任何收费后备方案。

## V5 的特殊情况

V5 即使估算为 `0 Anlas`，仍会消耗 Opus 的独立 Usage Limit。它会随时间回充，不能当作无限额度，也不能理解为每天固定赠送图片。

## 推荐指令

```text
先查询我的 NovelAI 账户和当前工具签名。
使用 V5、正常分辨率、28 steps、一次一张、无底图。
先估算费用；只有明确为 0 Anlas 才生成，否则不要执行。
```

## 切换高级版

如果你要使用新的 Vibe 编码、Director 去背景、Precise Reference、Enhance、专用放大、批量或高分辨率，请使用父项目的高级版 `openclaw-novelai`。严格版 `openclaw-novelai-free` 则只放行最窄的零估算图片路径。
