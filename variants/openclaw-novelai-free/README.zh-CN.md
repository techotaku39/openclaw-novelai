# OpenClaw NovelAI Free

这是一个严格限制在“零 NovelAI 图片 Anlas”范围内的 OpenClaw Skill 变体。

它保留小说写作、剧情规划、Prompt 设计、账户查询、费用估算、标签建议和本地记录。只有当当前账户和当前费用估算工具明确证明某次图片请求的费用为 `0 Anlas` 时，才允许生成一张图片。

它会禁止：

- 图生图；
- 普通局部重绘和扩图；
- Vibe Transfer；
- Precise Reference；
- Director 工具；
- Enhance；
- 专用放大；
- 批量、多样本和并行生图；
- 任何扣 Anlas 的降级或重试。

第一次成功完成零 Anlas 验证后，同一会话内只要计费参数不变，就可以持续复用验证结果，不设置时间或次数上限。网络或服务临时失败时，首次失败后最多顺序重试 3 次，参数完全不变；参数、鉴权、扣费、账户异常以及无法确认服务端是否已处理请求的情况不会自动重试。

## 重要区别

“零 Anlas”不等于“没有任何使用额度或费用”：

- Opus 的 V5 免费图片会消耗独立的 V5 Usage Limit；
- 如果 OpenClaw 把文字请求交给第三方模型，第三方模型可能单独收费；
- 网络、主机和其他模型的费用不属于本 Skill 的控制范围。

## 使用边界

如果费用估算工具缺失、返回空值、返回未知、无法确认当前账户权益，Skill 会拒绝生图。它不会因为用户说“我接受收费”就放行。

想使用付费图片功能，请改用父项目中的高级版 `openclaw-novelai`。
