# 零 Anlas 模式费用与额度说明

## 目标

这个变体的目标是：**不消耗 NovelAI Image Anlas**。

它不是“所有服务都免费”的承诺，也不是“无限生图”模式。它只允许当前工具明确估算为 `0 Anlas` 的图片请求。

## 允许的功能

| 功能 | 是否允许 |
| --- | --- |
| 小说大纲、续写、改写、审阅、总结 | 允许，不调用图片点数 |
| 本地读取和整理小说资料 | 允许 |
| 账户和订阅查询 | 允许，只读 |
| Anlas 费用估算 | 允许，只估算不执行 |
| 标签建议 | 允许，不生成图片 |
| Prompt、负面 Prompt、Seed 和场景规划 | 允许，只是准备工作 |
| 单张图片生成 | 只有估算明确为 `0 Anlas` 才允许 |

## 生图必须同时满足的条件

1. 当前账户有 Opus 或其他明确的免费生图权益；
2. 当前 MCP 暴露 `estimate_anlas_cost`；
3. 先把最终参数交给估算工具；
4. 返回明确的数值 `0 Anlas`；
5. 只生成一张；
6. 正常分辨率；
7. 不超过 28 steps；
8. 不使用底图、遮罩、参考图、Vibe、Precise Reference、Director、Enhance 或放大；
9. 不批量、不并行、不自动重试。

任一条件不满足，都不调用生图工具。

## 明确禁止的功能

- 图生图；
- 普通局部重绘、扩图；
- Vibe 编码和 Vibe 生图；
- Precise Reference；
- Director 工具；
- Enhance；
- 专用放大；
- 多张图片、多样本和并发生成；
- 任何收费后备方案。

## V5 的特殊情况

V5 即使估算为 `0 Anlas`，仍会消耗 Opus 的独立 Usage Limit。它会随时间回充，不能当作无限额度，也不能理解为每天固定赠送图片。

## 推荐指令

```text
先查询我的 NovelAI 账户和当前工具签名。
使用 V5、正常分辨率、28 steps、一次一张、无底图。
先估算费用；只有明确为 0 Anlas 才生成，否则不要执行。
```

## 切换高级版

如果你要使用图生图、局部重绘、Vibe、Director、参考图、批量或高分辨率，请使用父项目的高级版 `openclaw-novelai`。零 Anlas 变体不会为了完成任务而替你扣点数。
