# NovelAI 费用与额度说明

> 核对日期：2026-09-06。本文说明 NovelAI 服务侧的 Anlas、Opus 免费生图条件和 V5 使用额度，不构成 NovelAI 的价格承诺。官方规则、客户端显示和实际账户状态可能变化；生成前应以当前 UI 或可用的费用估算工具为准。

## 一、先分清三种资源

### 1. Anlas（图片点数）

Anlas 是 NovelAI 主要用于图片生成的点数。当前官方订阅说明写明：订阅用户的文字生成和 Text to Speech 无限，其他受计算资源影响的功能主要使用 Image Anlas。

Opus 订阅每月包含 10,000 Subscription Anlas；Tablet 和 Scroll 各包含 1,000。Subscription Anlas 按订阅周期补充，Paid Anlas 是另外购买的点数，通常在订阅侧余额用完后才使用。

### 2. Opus 的 V5 免费使用额度

Opus 的 V5 免费生图还有一个独立的、会自动回充的 Usage Limit。它不是 Anlas，也不是每天零点发放的固定张数。

当符合免费条件时，V5 生图会消耗这个额度而不是 Anlas。额度耗尽后仍可继续生成，但请求会改为消耗 Subscription Anlas 或 Paid Anlas。

### 3. OpenClaw 或其他模型的费用

小说整理、Prompt 改写和规划可能由 OpenClaw 当前选择的文字模型完成。如果那个模型来自 OpenAI、Anthropic、DeepSeek 或其他按量计费的提供商，它的费用与 NovelAI Anlas 分开计算。本 Skill 本身不收取额外费用。

## 二、明确不消耗 NovelAI Anlas 的功能

以下操作本身不生成图片，因此不消耗 NovelAI Anlas：

| 功能 | 说明 |
| --- | --- |
| NovelAI 文字生成 | 活跃订阅内无限；具体模型仍受订阅等级限制 |
| NovelAI Text to Speech | 活跃订阅内无限 |
| 小说项目初始化、上下文整理、章节规划 | 本地文件操作或文字模型调用，不是图片点数 |
| `get_subscription`、`get_user_data` | 只读账户查询 |
| `estimate_anlas_cost` | 只做费用估算，不执行生成 |
| `suggest_tags` | 标签建议，不执行图片生成 |
| Prompt、负面 Prompt、Seed、标签、质量标签 | 不单独收费；它们只会影响所属图片请求 |
| `annotate_image` | 作为 ControlNet 等预处理时不产生最终图片；若随后生成图片，生成请求仍按规则计费 |

“不消耗 Anlas”不等于“没有任何模型成本”：文字模型可能有自己的 API 计费，V5 免费图还会消耗独立的 Usage Limit。

## 二点一、同一会话的费用配置复用与临时重试

主 Skill 在完成账户或费用验证后，可以只在当前会话内保留脱敏的计费参数。只要操作类型、模型、尺寸、Steps、图片数量、采样器/缩放/噪声、底图、遮罩、参考图、Vibe 和 Director 操作不变，就可以持续复用，不设置时间或次数上限。新会话、重启、参数变化、账户警告、工具报错、无法确认请求是否已处理，或用户主动要求复查时，才失效并重新验证。

一次用户生图请求遇到明确的临时失败时，首次失败后最多顺序重试 3 次，参数完全不变。参数、鉴权、扣费、账户、Usage Limit 异常以及有重复处理风险的结果不自动重试。

## 三、Opus 免费图片的条件

Opus 的基础免费图片需要同时满足以下条件：

1. 使用 Opus 可用的订阅和模型；
2. 一次只生成一张；
3. 使用正常分辨率范围；
4. Steps 不超过 28；
5. 不使用另一张图片作为底图。

官方订阅页面同时使用了“Normal Sized”这一尺寸描述，官方 FAQ 则概括为正常分辨率。不要仅凭“Small”这个 UI 名称判断免费，应该让当前客户端或费用估算工具显示 `0 Anlas` 后再执行。

### V4.5 及更低模型

官方说明：V5 以前的图片模型不受 V5 Usage Limit 影响，在满足常规免费条件时可以持续使用。高分辨率、超过 28 steps、批量生成或其他额外功能仍可能消耗 Anlas。

### V5

V5 在满足免费条件时消耗 Opus 的独立 Usage Limit。账户界面会动态显示剩余百分比、约可生成的图片等价数量和回充速度。

有些账户或时段可能会显示约 11%/天、约 190 张图片/天；这里的数字只是当前界面显示的回充速度示例，不是每天固定赠送 190 张。额度会持续按时间恢复；图片尺寸、Steps 和系统当前规则都会影响实际可生成数量。官方说明完全耗尽后大约需要一周回满。

## 四、当前 Opus 账户的实测矩阵

以下结果来自 2026-09-06 对一个有效 Opus 账户的真实 API 测试。测试图片使用正常尺寸，单张请求；测试前后查询 Subscription Anlas、Paid Anlas 和 V5 Usage Limit。收费项随后又使用共享 Token 做了连续前后双采样复测，测试期间没有检测到外部余额漂移。

| 操作 | 实测结果 | 备注 |
| --- | --- | --- |
| V5 / V4.5 单张文生图 | 0 Anlas | 8 和 28 steps、正常尺寸 |
| V4.5 图生图 | 0 Anlas | 8 和 28 steps、正常尺寸；仅代表当前 Opus 参数 |
| V4.5 局部重绘 | 0 Anlas | 8 和 28 steps、正常尺寸；仅代表当前 Opus 参数 |
| 已编码 V4/V4.5 Vibe 生图 | 0 Anlas | 新建 Vibe 编码不在此项内 |
| `annotate_image` | 0 Anlas | 作为 ControlNet 预处理测试 |
| Director 线稿、草图、去杂物、上色、表情 | 0 Anlas | 正常尺寸输入 |
| Director 去背景 | 65 Anlas | 本次真实账户扣费 |
| Vibe 编码 | 2 Anlas | V4+ 编码一次；重编码会再次收费 |
| 一次生成 2 张 | 8 Anlas | 本次真实账户扣费 |
| 1536×1024 单张 | 12 Anlas | 本次真实账户扣费 |
| 29 steps 单张 | 20 Anlas | 本次真实账户扣费 |
| 专用放大 | 未生成 | 当前 `/ai/upscale` 返回 404 |
| Enhance、Precise Reference | 未测试 | 当前参考 MCP 未暴露对应独立工具 |

这些是当前账户、当前 MCP 版本和具体参数的经验结果，不是 NovelAI 永久价格承诺。特别是图生图、局部重绘和部分 Director 工具，虽然本次为 0 Anlas，仍应在每次操作前估算并在操作后审计余额。

## 五、会消耗 Anlas 或需要特别确认的功能

| Skill 功能或参数 | Anlas 规则 |
| --- | --- |
| 普通 `generate_image` | 非 Opus 或不满足免费条件时收费；Opus V5 免费额度耗尽后也收费 |
| 一次生成多张 | 即使是 Opus，也会消耗 Anlas；批量数量越多，费用越高 |
| 更高分辨率 | 通常消耗 Anlas |
| 超过 28 steps | 通常消耗 Anlas |
| 使用底图的 `image_to_image` | 当前 Opus 标准参数实测为 0；官方条件更保守，必须精确估算并审计余额 |
| 普通 `inpaint` | 当前 Opus 标准参数实测为 0；其他尺寸、模型或参数仍可能收费 |
| Focused Inpainting | 官方明确说明 Opus 对大图区域可以 0 Anlas；仍应以当前工具估算为准 |
| `enhance` | 会再次经过 NovelAI Diffusion，属于再次图片处理/生成，按可能收费处理 |
| `encode_vibe` | V4 及以上模型编码一次收取 2 Anlas；修改 Information Extracted 后重新编码还会再次收费 |
| Vibe 生图 | 基础图片请求的规则仍适用；V4 及以上模型超过 4 个 Vibe 后，每多一个额外收取 2 Anlas |
| Precise Reference | 官方说明每张参考图、每次图片生成额外 5 Anlas；当前只支持 V4.5 |
| `director_tool` | 线稿、草图、去杂物、上色、表情本次为 0；背景移除实测 65，其他操作不能默认免费 |
| `annotate_image` | 本次 ControlNet 标注预处理为 0；后续图片生成仍按生成请求计费 |
| `upscale_image` | 当前参考环境的专用 `/ai/upscale` 路由返回 404，没有成功生成；如果未来恢复，仍应先估算 |

多角色提示、角色位置、Seed、Sampler、负面 Prompt 和普通标签不会单独产生费用；它们的费用归属于这次图片请求。

## 六、两个 Skill 变体的策略

- `openclaw-novelai-free`：最保守，只允许当前估算明确为 0 Anlas 的窄范围图片请求，不放行图生图、局部重绘和 Director。
- `openclaw-novelai-opus-free`：要求有效 Opus、正常尺寸、单张、≤28 steps、估算为 0，并放行本次实测免费的图生图、局部重绘、已有 Vibe 生图、标注和部分 Director；每次成功后审计余额，发现扣点立即停止。
- 两个变体都禁止 Vibe 编码、Director 去背景、Precise Reference、Enhance、专用放大、批量、高分辨率和超过 28 steps。

## 七、最安全的使用方式

涉及任何图片输出时，先让 AI 这样做：

```text
先查询我的 NovelAI 订阅和余额，再根据当前工具估算这次操作的 Anlas。
请展示模型、图片尺寸、Steps、生成张数、参考图/Vibe 数量和预计费用。
如果预计不是 0 Anlas，先不要执行，等我确认。
```

确认免费 V5 单张时，可以这样说：

```text
使用 V5，在正常分辨率、28 steps、一次一张、无底图的条件下生成。
先告诉我当前估算是否为 0 Anlas；如果不是 0，不要生成。
```

进行 Vibe、局部重绘、Director、Enhance 或批量操作时，不要只说“免费试一下”，而应明确要求先估算费用。

## 八、关键判断口诀

- 文字和 TTS：订阅内不扣 NovelAI Anlas。
- 查询、估算、标签建议、本地记录：不扣 Anlas。
- Opus + 单张 + 正常尺寸 + 不超过 28 steps：可能 0 Anlas；图生图和局部重绘必须以当前估算和余额审计为准。
- V5 的 0 Anlas：会消耗独立 Usage Limit，不是无限电量。
- 批量、高分辨率、超过 28 steps、Vibe 编码、参考图、去背景和再次处理：默认按收费或未验证处理。
